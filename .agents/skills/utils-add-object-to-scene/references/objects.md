# Object conventions

- Runtime artwork: `public/assets/objects/<kebab-case-id>/`; code: `src/game/objects/<id>/definition.ts` and a named PascalCase class.
- Export `definition: GameObjectDefinition`. Keys start with `object:<id>:`; asset paths start with `objects/<id>/`, relative to Preloader's existing `assets` path. Do not prefix them with `assets/` again.
- `ObjectAsset` supports image, fixed-frame spritesheet, and atlas plus JSON data. `ObjectAnimation` lists explicit texture/frame pairs and repeat/frameRate. Definitions are discovered by eager Vite glob; no loader registry edits.
- `visual` selects initial texture/frame, scale/depth and optional animation; named `variants` override those visual defaults. Object classes can add local behavior settings alongside the definition.
- Extend composition-based `SceneObject`; its sprite is the visible root and optional body is the collider. Constructor options: x/y, size (display width with uniform scaling), depth and variant. Use `setSize` and `setPosition` to synchronize bodies.
- Physics dimensions are unscaled texture pixels. `SceneObject` handles centered offsets and the difference between scaled dynamic and static bodies. Circular objects must use uniform scale.
- Use `ObjectDepth` from `src/game/visual/layers.ts` (background 0, Sun 5/surface 6, planets 10, indicators 11, ship 20, projectiles 21, UI 100). World sprites and the space starfield scroll normally; HUD uses scrollFactor(0). Screen-fixed backgrounds are optional scene-specific effects.
- Scene creates instances, updates behavior and connects relationships. Default Game placements are in `gameObjects.ts`; integrate other scenes directly or in their own layout module. Game's ship remains the camera target; new planets, projectiles and other objects do not replace it.
- Planet instances reference Phaser-independent `PlanetWorldState` from `src/game/world/planetWorldState.ts`, carrying ID, name, world x/y and radius. This is spatial presentation state, not economy/domain state. Generic collisions consume `CircleObstacle` from `src/game/world/geometry.ts`. `Game` creates fresh world-state copies on entry; pass one as `PlanetOptions.model`. Model changes update sprite/body/label on the next scene update; wrapper position/size setters also update the model.
- Keep object-owned effects in the object's module. Use `src/game/effects/` only for scene/world-wide effects that do not import object modules. Follow the canonical [architecture guide](../../../../context/foundation/architecture.md).
- Register owned overlay/listener/timer cleanup with `ownCleanup`; wrapper destruction on shutdown is idempotent. Let Phaser own sprite animation ticking. Do not register a second per-frame listener if the scene already calls update.
- When audio is requested, use [audio ownership](../../utils-add-sound/references/audio.md). In an object's constructor, create a scope with `getAudioService(scene.game).createScope(scene)` and register `this.ownCleanup(scope.destroy)`. Scene-owned sounds may share the scene scope instead. Update a scope only from its chosen owner.
- Scaffold defaults to no physics; generated physics defaults to rectangle and depth defaults to Planet as a starting point, not an object classification. Choose the final depth during integration. It refuses occupied object/asset directories and duplicate definition IDs/keys; it never edits a scene automatically.
