## Notes

Signed-in user can abandon a run, see save status, preserve progress, and resume an active run

Additional requested behavior: automatically save on every complete minute boundary of the remaining-time clock and when returning to Main Menu. Show the autosave result immediately below the in-game Menu button during gameplay, or below the Main Menu controls while there, for two seconds. Offer Continue in Main Menu when an active save is available.

When Continue is available, selecting New Game requires confirmation before abandoning the saved run; confirming deletes that run's saved progress, while cancelling preserves it. After a terminal result is retained in personal history and its global score submission succeeds, delete all active-run saves belonging to the player. Completed results remain distinct from active-run saves.

Persistent active-run saves are available only to signed-in players with a created profile. Anonymous players cannot create, access, or resume saved game state.

S-11 also includes the former S-14 terminal-save cleanup scope; there is no separate S-14 change.
